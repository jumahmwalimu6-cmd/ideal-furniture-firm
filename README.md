## 🎨 Design

- **Primary colour:** Warm Brown `#6B3A2A`
- **Accent colour:** Gold `#C8963E`
- **Background:** Cream `#F5ECD7` / `#FDF8F0`
- **Typography:** Georgia (headings) + Segoe UI (body)
- **Icons:** Emoji-based (no external dependencies)
- **Responsive:** Mobile-first, works on all screen sizes

---

## 💬 WhatsApp Integration

Every product card has an **Order via WhatsApp** button that opens a pre-filled WhatsApp message with the product name and price. The contact form also submits via WhatsApp.

**To update the WhatsApp number**, find and replace `254700000000` with your real number (in international format, no `+` or spaces) across all HTML files.

## 🚀 How to Use

1. **Open locally:** Double-click `index.html` to open in any browser
2. **No server needed:** Pure HTML + CSS, works offline
3. **Update contact details:** Replace phone/WhatsApp numbers in all 5 HTML files
4. **Add real photos:** Replace the emoji placeholders in product cards with `<img>` tags
5. **Deploy online:** Upload all files to any web host (Hostinger, GoDaddy, Netlify, etc.)
